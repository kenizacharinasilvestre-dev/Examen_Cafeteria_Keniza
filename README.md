2. Descripción del programa

Sistema de pedidos de una cafetería desarrollado en C#.

3. Datos de entrada

* Cliente y fecha.
* Producto y precio.
* Cantidad.
* Tamaño.
* Servicio.
* Cliente frecuente.
* Porción extra.

4. Proceso

Agregar productos, calcular precios, aplicar descuentos, empaque e ITBIS.

5. Salida

Lista de pedidos, subtotal, descuento, empaque, ITBIS y total a pagar.
